# Keyboard shortcuts

Every shortcut in Droid Shuttle. There is no system-wide hotkey: shortcuts work while the app is in front.

> [!NOTE]
> **F5 to F8 on a Mac keyboard** usually need **Fn** held down, unless **Use F1, F2, etc. keys as standard function keys** is turned on in System Settings. The same actions are available in the context menu and as buttons in the function bar.

## Everywhere

| Shortcut | Action |
|---|---|
| ⌘K (or Ctrl+K) | Open or close the command palette |
| ⌘Q | Quit (the standard macOS shortcut; it ends running transfers) |

## Files

The first two tables are active anywhere on the Files screen when focus is not in a text field and no dialog is open. The third needs the pane to have focus.

### Two-pane mode only

| Shortcut | Action |
|---|---|
| F5 | Copy the active pane's selection to the other pane |
| F6 | Move it to the other pane |
| F7 | New folder in the active pane |
| F8 | Delete in the active pane |
| ⌘U | Swap the panes |
| Tab | Switch to the other pane |

### Any mode

| Shortcut | Action |
|---|---|
| ⌘C | Copy |
| ⌘X | Cut |
| ⌘V | Paste |
| ⌥⌘V | Paste as a move |
| ⌘D | Duplicate |
| ⌘A | Select everything visible |

### In a pane (the pane has focus)

| Shortcut | Action |
|---|---|
| ↑ ↓ (and ← → in icon view) | Move the selection. Hold ⇧ to extend it |
| Enter | Rename (exactly one item selected). It does **not** open |
| Space | Quick Look (one item selected, not a folder) |
| Delete or ⌫ | Delete. On the phone it works on its own; on the Mac it needs **⌘** (⌘⌫) and moves to the Trash |
| Esc | Clear the selection. While renaming: cancel. During a drag: cancel the drag |
| ⇧⌘N | New folder |
| ⌘[ / ⌘] | Back / Forward |
| ⌘↑ | Enclosing folder |
| ⌘↓ | Open the selected folder |

### While renaming

| Shortcut | Action |
|---|---|
| Enter | Commit |
| Esc | Cancel |

### Modifier keys while dragging

| Drop | Default | Hold |
|---|---|---|
| Same side | Move | ⌥ to copy |
| Other side | Copy | ⌘ to move |

## Gallery

| Shortcut | Action |
|---|---|
| Arrow keys (⇧ to extend) | Move the selection |
| Space or Enter | Open the viewer |
| ⌘A | Select everything in the current view |
| ⌘C | Copy |
| Esc | Clear the selection |

### Viewer

| Shortcut | Action |
|---|---|
| ← / → | Previous / next item |
| Scroll wheel | Zoom (images) |
| `0` | Reset zoom |
| `i` | Show or hide details |
| ⌘C | Copy the file |
| Esc | Close |

## Mirror

Active when the picture has focus. Other ⌘ and Ctrl combinations are not forwarded to the phone.

| Shortcut | Action on the phone |
|---|---|
| ⌥H | Home |
| ⌥B (or right-click, or Esc) | Back |
| ⌥S | Recents |
| ⌥P | Power |
| ⌥O | Screen off / on |
| ⌥R | Rotate |
| ⌥N | Notification panel |
| ⌥⇧N | Quick Settings panel |
| ⌥↑ / ⌥↓ | Volume up / down |
| ⌘V | Paste the Mac's clipboard text |
| Enter, Backspace, Tab, Delete, arrows, Home, End, Page Up, Page Down | The matching Android key |
| Any single character | Typed on the phone |

## Tools

The Terminal tab sends your keystrokes to the shell on the phone. The Log tab has no keyboard shortcuts of its own.
