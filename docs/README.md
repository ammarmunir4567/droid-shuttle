## Conventions used in these pages

- **Bold** text is something you see on screen: a button, a heading or a menu item. The wording is copied from the app.
- `Code style` is a key, a path, a command or a file name.
- Sizes follow the app and use decimal units (1 GB = 1000 MB).
- Statements about behaviour were checked against the source code. Where something is a limit or a surprise, it is called out in a **Limits** section on the relevant page.
- The screenshots show the app's built-in demo phone (a "Pixel 8 Pro" with made-up files), not real data.
